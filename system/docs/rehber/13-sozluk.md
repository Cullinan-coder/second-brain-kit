# 13 · Sözlük

Rehberde geçen terimler, alfabetik.

| Terim | Anlamı |
|---|---|
| **Açık konular** | Yarım kalan işlerin listesi; Claude Code oturum başında bunu görür |
| **Aralıklı tekrar** | Bilgi kartlarını unutmaya yakın zamanlarda tekrar ettiren çalışma yöntemi ([Bilgi kartları](moduller/cards.md)) |
| **Ajan** | Belirli bir işi (ders asistanı, mail özetleyici…) kendi kısıtlı izinleriyle yapan yardımcı; sonuçlarını sana onaya sunar |
| **API** | Programların birbiriyle konuşma arayüzü |
| **API anahtarı** | Bir bulut hizmetini kendi hesabın adına kullanmanı sağlayan gizli yazı; kullandıkça ücret yazabilir ([API anahtarları](04-api-anahtarlari.md)) |
| **Arşiv (`90-Arşiv`)** | «Silinen» notların taşındığı klasör; kalıcı silme yoktur |
| **Asistan** | Kasanı bilen yerel sohbet yardımcısı ([Asistan kullanımı](09-asistan-kullanimi.md)) |
| **Bağlam penceresi (`num_ctx`)** | Modelin bir seferde “aklında tutabildiği” metin miktarı |
| **Bağlayıcı (connector)** | Bir veri kaynağının dosya biçimini okuyan küçük bileşen |
| **Beyin dizini** | Notların, maillerin, belgelerin hem kelime hem anlamla aranabilir indeksi (`brain.db`) |
| **Beyne at** | Panodaki metni/bağlantıyı ya da ekran görüntüsünü (Ctrl+Alt+B) kasaya kaydeden özellik |
| **Bulut süzgeci** | Bulut modele giden metinden gizli bilgileri maskeleyen katman |
| **CalDAV / CardDAV** | Takvim / kişi senkronu standartları (iCloud kullanır) |
| **Claude Code** | Anthropic'in komut satırı kodlama/asistan aracı; Second Brain ona hafıza verir |
| **Claude Desktop** | Anthropic'in masaüstü Claude uygulaması; MCP bağlanabilir |
| **CUDA / cuDNN / cuBLAS** | NVIDIA ekran kartında yapay zekâ hesabı için kütüphaneler |
| **Deneme kipi (sandbox)** | Kurulumu gerçek sisteme dokunmadan denemek ([Kurulum](01-kurulum.md)) |
| **Dışa aktarma (export)** | Bir hizmetten verini dosya olarak indirmek |
| **Dry-run / önizleme** | Hiçbir şey yazmadan «ne olacağını» göstermek |
| **Embedding / gömme** | Metni sayı vektörüne çevirip anlam benzerliği hesaplamak |
| **Frontmatter** | Bir notun en üstündeki `---` arası bilgi bloğu (`visibility: private` gibi) |
| **GANO** | Genel not ortalaması; `sb gpa` hesaplar, «ya olursa» senaryosu dener |
| **Gatekeeper** | macOS'un imzasız uygulama koruması |
| **git** | Dosya sürüm denetimi; kasanı geri alınabilir yapar |
| **GPU / VRAM** | Ekran kartı / ekran kartı belleği; model boyutunu belirler |
| **Hazır seçim (preset)** | Meslek, donanım, gizlilik, yoğunluk eksenlerinin birleşimi ([Hazır seçimler](15-hazir-secimler.md)) |
| **Hafıza kancaları (hooks)** | Claude Code oturumlarında bağlamı ekleyen/özet çıkaran otomatik tetikleyiciler |
| **IMAP** | Mail okuma protokolü; Outlook, iCloud, Yandex, okul/şirket maili için |
| **İçe aktarma (import)** | Dışa aktarma dosyasını kasaya çevirmek |
| **İstem enjeksiyonu** | Mail/web gibi içeriğe gizlenmiş «şunu yap» komutlarıyla asistanı kandırma girişimi |
| **İzin profili** | Asistanın neleri sormadan yapabileceğini belirleyen ayar (sıkı / normal / serbest) |
| **Kasa (vault)** | Notlarının bulunduğu klasör |
| **keyring / şifre kasası** | İşletim sisteminin şifre saklama alanı (Windows Kimlik Bilgisi Yöneticisi, macOS Anahtar Zinciri) |
| **Kit** | Kurulabilir sürüm paketi |
| **Modül** | Birbiriyle ilgili özellikleri gruplayan açılıp kapanabilen birim ([Modüller](16-moduller.md)) |
| **MCP** | Model Context Protocol: yapay zekâ asistanlarına araç bağlama standardı ([MCP](06-mcp.md)) |
| **Madde** | 250'lik özellik kataloğunun tek bir kalemi |
| **Makbuz (`sb receipt`)** | Bir işin sonucunu kaynak bağlantısıyla tek satır kaydeden not |
| **Maskeleme** | Hassas veriyi `[… gizlendi]` ile değiştirme |
| **OAuth** | Parolanı paylaşmadan bir uygulamaya hesabına sınırlı erişim verme yöntemi |
| **Obsidian** | Markdown not uygulaması; kasayı görsel gezmek için |
| **Ollama** | Yerel yapay zekâ modellerini çalıştıran program |
| **Onay kartı** | Dış etkili işlerden önce çıkan Onayla/İptal kartı |
| **OTP** | Tek kullanımlık doğrulama kodu |
| **Port** | Bir ağ programının dinlediği kapı numarası (asistan: 8765; IMAP: 993) |
| **PWA** | Ana ekrana eklenen, uygulama gibi çalışan web sayfası (telefon erişimi) |
| **Qwen** | Yerel çalıştırılan model ailesi (örn. `qwen3:8b`) |
| **Redact** | Gizli veriyi gizleme |
| **Salt okunur** | Yalnız okuma izni; değiştiremez, silemez |
| **Scope (izin kapsamı)** | OAuth'ta hangi veriye erişileceği (`gmail.readonly` gibi) |
| **SmartScreen** | Windows'un bilinmeyen program uyarısı |
| **SSRF** | Sunucunun yerel ağa istek attırılarak kandırılması; URL çekme buna karşı korunur |
| **STT / TTS** | Sesi yazıya çevirme / yazıyı sese çevirme |
| **Syncthing** | Cihazlar arası doğrudan klasör eşitleme programı |
| **Tailscale** | Cihazlarını özel bir ağda bağlayan hizmet |
| **Tam yerel** | Hiçbir isteğin buluta gitmediği gizlilik seçimi |
| **Takma ad (alias)** | Bir hesaba verdiğin kısa ad |
| **Tepsi (system tray)** | Görev çubuğunun sağındaki küçük simge alanı |
| **Token / belirteç** | Bir erişimi kanıtlayan gizli yazı; ayrıca modellerde metin birimi |
| **Uygulama şifresi** | İki adımlı doğrulama açıkken harici programlar için üretilen tek amaçlı şifre |
| **uv** | Python ortamlarını kuran hızlı araç |
| **Whisper (faster-whisper)** | Konuşmayı yazıya çeviren yerel model |
| **Yoğunluk** | Kaç özelliğin açılacağını belirleyen hazır seçim ekseni |
| **Zamanlanmış görev** | İşletim sisteminin belirli saatlerde çalıştırdığı iş (`SecondBrain-Daily` vb.) |
