# Second Brain Asistan — Obsidian eklentisi

Yerel asistan sunucusuyla (`http://127.0.0.1:8765`) konuşur; dışarıya veri göndermez. Derleme yok.

## Elle kurulum
1. Asistan sunucusunun çalıştığından emin ol.
2. Bu klasörü (`manifest.json`, `main.js`, `styles.css`) kasanın `.obsidian/plugins/second-brain-assistant/` klasörüne kopyala.
3. Obsidian: Ayarlar > Topluluk eklentileri > (kısıtlı modu kapat) > "Second Brain Asistan"ı etkinleştir.

## Kullanım
- Sol şeritteki beyin simgesi ya da "Sohbet panelini aç": sağ panelde sohbet; kaynak kartına tıklayınca not açılır.
- Komut paleti: **Beyne sor (seçili metinle)**, **Bu notu özetle**, **Benzer notlar**, **Bugünün planı**.
- Sunucu kapalıysa nazik bir uyarı görünür. Adres eklenti ayarlarından değiştirilebilir (yalnız yerel adres kullan).
