# Asistan

Yerel Qwen asistanı: kasadan bilgi sorar, takvime ekleme **önerir** (sen "Onayla" demeden eklemez).
Açılmazsa: bilgisayarda `SecondBrain-Chat` görevi çalışıyor olmalı; elle başlatmak için `uv run python -m sb chat` (`_system` klasöründe).
