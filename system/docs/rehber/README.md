# Second Brain 1.0 — kullanıcı rehberi

Bu rehber Second Brain'i kurmaktan günlük kullanıma, hesap bağlamaktan sorun gidermeye kadar **her şeyi adım adım** anlatır. Teknik bilgi gerekmez: her yerde «şuna tıkla → şunu gör» biçimi kullanılır.

> Bu klasör `tools/build_guide.py` ile üretilir; elle yazılan bölümler `docs/rehber-src/` içindedir. Burayı elle düzenleme.

## Nereden başlamalıyım?

1. Ürünü tanımak için [00 · Başlangıç](00-baslangic.md).
2. Kurmak için [01 · Kurulum](01-kurulum.md), sonra [02 · Sihirbaz adım adım](02-sihirbaz-adim-adim.md).
3. Bir şey takılırsa [11 · Sorun giderme](11-sorun-giderme.md).
